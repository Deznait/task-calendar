# Task Calendar - Custom Agents

Agentes especializados para el proyecto Task Calendar, una aplicación de gestión de tareas con calendario construida con Quasar, Vue 3 y TypeScript.

---

## Calendar Agent

**Propósito:** Especializado en lógica de calendario, recurrencia de tareas y manejo de fechas.

**Áreas de experiencia:**

- Lógica de recurrencia con RRule (rrule.js)
- Cálculo de ocurrencias de tareas
- Manipulación de fechas con date-fns
- Componentes de calendario y vistas
- Gestión de excepciones de tareas (exdates)

**Archivos principales:**

- `src/composables/useCalendar.ts`
- `src/pages/IndexPage.vue`
- `src/components/`
- `dev/sql/create_tables.sql`

**Comandos útiles:**

```bash
pnpm dev         # Inicia desarrollo
pnpm lint        # Valida código
pnpm format      # Formatea archivos
```

## Database Agent

**Propósito:** Gestión de base de datos Supabase, queries y esquema de datos.

**Áreas de experiencia:**

- Configuración y conexión a Supabase
- Definición de tipos Task, TaskCompletion, TaskOverride
- Queries a tablas: tasks, task_completions, task_overrides
- Autenticación y seguridad
- Sincronización de datos

**Archivos principales:**

- `src/boot/supabase.ts`
- `src/stores/tasks.store.ts`
- `src/stores/auth.store.ts`
- `src/types/index.ts`
- `dev/sql/create_tables.sql`

**Tipos principales:**

- `Task` - Tarea con soporte de recurrencia
- `TaskCompletion` - Registro de completamiento
- `TaskOverride` - Modificaciones a ocurrencias específicas

## Guía de uso

Para invocar un agente específico, usa:

```
@<agent-name> <tarea>
```

Ejemplos:

- `@Calendar Agent: ¿Cómo calculo las ocurrencias de una tarea recurrente?`
- `@Database Agent: ¿Cómo obtengo las tareas completadas entre dos fechas?`
- `@Component Agent: Crea un nuevo componente para mostrar categorías`
- `@State Management Agent: Refactoriza el store de tareas`
- `@i18n Agent: Añade nuevas traducciones al español`

---

**Stack tecnológico:**

- Framework: Quasar 2 + Vue 3 + TypeScript
- Base de datos: Supabase (PostgreSQL)
- Estado: Pinia
- Enrutamiento: Vue Router 5
- Internacionalización: Vue I18n 11
- Recurrencia: RRule.js
- Fechas: date-fns
- Almacenamiento: idb-keyval
